1.1. What is Python?

Python is a high-level, general-purpose programming language known for its simple and readable syntax. It is widely used for software development, web development, data analysis, artificial intelligence, machine learning, automation, scientific computing, and education.
Python allows programmers to express complex operations using relatively short and readable programs. Its syntax is designed to be easy to understand, which makes Python especially popular among beginners as well as professional developers.
One of the important features of Python is that it is interpreted in the traditional description of Python's execution model. Python source code is processed by the Python implementation, which converts it into an intermediate form called bytecode and executes it using the Python virtual machine. Modern Python implementations may use additional execution techniques, but the important point for beginners is that Python provides an execution environment that hides much of the low-level machine detail from the programmer.

1.1.1 Introduction to Programming

Programming is the process of giving instructions to a computer so that it can perform a particular task. A computer cannot understand human languages such as English or Hindi directly. Therefore, programmers use special languages called programming languages to write instructions that can be translated into a form the computer can understand and execute.
A programming language provides a set of rules, symbols, keywords, and syntax for communicating with a computer. Using programming languages, we can develop applications, websites, games, operating systems, artificial intelligence systems, databases, and many other types of software. Examples of programming languages include C, C++, Java, Python, JavaScript, and C#.
Programming languages are generally designed to make it easier for humans to write computer instructions. Some languages are closer to human language and are called high-level languages, while others are closer to the instructions understood directly by the computer. Python is an example of a high-level programming language.

1.1.2 Programming Language

A programming language is a formal language used by programmers to write instructions that tell a computer what to do. These instructions are written according to the syntax and rules of the particular programming language.
For example, in Python, the instruction print ("Hello World") tells the computer to display the words "Hello World" on the screen. The programmer does not need to write the complicated machine instructions required to display the text because Python provides simple commands for this purpose.
Programming languages can be classified into different categories. Low-level languages are closer to the computer's hardware and include machine language and assembly language. High-level languages are easier for humans to understand and include Python, Java, C++, and JavaScript.

1.1.3 What is Binary Language

Binary language, commonly called binary code, is a system that uses only two digits: 0 and 1. Computers use electronic circuits that have two basic states, such as ON and OFF. These two states can be represented by 1 and 0, respectively.
A single binary digit is called a bit. Eight bits make one byte. Computer data and instructions are ultimately represented internally using combinations of 0s and 1s. For example, a computer may represent a piece of information using a sequence such as 01001000.
Machine language is the lowest-level programming language and consists of instructions represented in the form that the computer's processor can execute directly. Humans generally find binary instructions difficult to read and write, so higher-level programming languages and translators are used to make programming easier.

1.1.4 History of Python

Python was created by Guido van Rossum, a Dutch programmer. The development of Python began in the late 1980s, and the first public release of Python was made in 1991.
Guido van Rossum began working on Python as a successor to the ABC programming language. He wanted to create a programming language that was powerful but also easy to read and use. The language was designed with an emphasis on code readability, simplicity, and programmer productivity.
The name Python was not taken from the snake. Guido van Rossum named the language after the British comedy group Monty Python, whose television program Monty Python's Flying Circus he enjoyed. This is why Python's documentation and examples have sometimes included humorous references to Monty Python
The Python programming language is developed as an open-source project, with contributions from programmers around the world. The Python Software Foundation (PSF) supports and promotes the development and use of Python.

1.1.5 Advantages of Python

•	Easy to Read: Python has a simple and clear syntax, making programs easy to read and understand.
•	Easy to Learn: Python is beginner-friendly and is widely used for teaching programming.
•	Short and Simple Programs: Python often requires fewer lines of code compared with many other programming languages.
•	Large Community: Python has a large community of programmers and developers who provide support and guidance.
•	Extensive Libraries: Python provides many built-in and third-party libraries for different types of programming tasks.
•	Large Amount of Documentation: Programmers can easily find tutorials, documentation, examples, and solutions to common problems.
•	Versatile Language: Python can be used for many purposes, including web development, automation, data science, and artificial intelligence.
•	Cross-Platform: Python programs can run on different operating systems such as Windows, macOS, and Linux.
•	Useful for Professional Projects: Python is suitable for both small educational programs and large professional applications.
•	Useful in Modern Technologies: Python is widely used in fields such as artificial intelligence, machine learning, data science, and scientific computing.

1.1.6 Limitations of Python

•	Slower Execution: Python can be slower than languages such as C and C++ for certain CPU-intensive tasks.
•	Higher Memory Usage: Python programs can sometimes consume more memory than programs written in lower-level languages.
•	Not Ideal for Very High Performance: Python may not be the best choice for applications that require extremely fast execution.
•	Limited Low-Level Hardware Control: Python is not generally preferred when direct and detailed control over computer hardware is required.
•	Performance-Intensive Applications: Applications requiring very high computational performance may benefit from languages such as C or C++.
•	Can Use Other Languages for Performance: Python can be combined with faster languages and optimized libraries when high performance is required.

Print Function in Python
The print() function is one of the most commonly used built-in functions in Python. It is used to display information, messages, variables, calculations, and results on the output screen.
The main purpose of the print() function is to communicate information from a program to the user. Whenever a program needs to show data, instructions, results, or status messages, the print() function is used.
The print() function provides several parameters that help control how the output appears. Two important parameters are sep and end.

sep = Controls the space or separator between printed values. 
end = Controls what happens after the output is printed.

sep Parameter (Separator)
The word sep stands for Separator.
When multiple values are printed in a single print() statement, Python automatically places a separator between them. The sep parameter allows the programmer to control what character or string is inserted between those values.
Purpose of sep
•	Controls the spacing between multiple output items.
•	Improves readability of output.
•	Allows customization of output formatting.
•	Can join multiple values using any symbol or text.
Default Behavior
If the sep parameter is not specified, Python uses a single space as the separator.
Features of sep
•	Works only when two or more values are being printed together.
•	Accepts strings as separators.
•	Can be a space, comma, dash, colon, special symbol, or even an empty string.
•	Helps create formatted output without manually joining strings.
Uses of sep
•	Displaying names and values neatly.
•	Creating custom formatted text.
•	Generating reports and tables.
•	Formatting file paths, dates, or addresses.
•	Joining output elements with specific symbols.

end Parameter
The word end refers to the character or string that is added after the output is printed.
After displaying output, Python automatically places something at the end. The end parameter controls what is added after printing.
Purpose of end
•	Controls where the next output begins.
•	Decides whether output should continue on the same line or move to a new line.
•	Helps create customized output layouts.
Default Behavior
If the end parameter is not specified, Python automatically inserts a newline character after printing. This causes the next output to appear on the next line.
Features of end
•	Added after the entire output is printed.
•	Accepts any string value.
•	Can remove the newline behavior.
•	Can add symbols, spaces, arrows, commas, or custom messages after output.
•	Useful for formatting continuous output.
Uses of end
•	Keeping multiple outputs on the same line.
•	Designing menus and prompts.
•	Creating formatted reports.
•	Building progress indicators.
•	Controlling the appearance of output screens.
Key points:
1.	print() is used to display output on the screen.
2.	sep controls the separation between multiple values.
3.	The default separator is a single space (" ").
4.	end controls what is added after printing.
5.	The default end value moves the cursor to the next line ("\n").
6.	sep affects the middle part of the output.
7.	end affects the final part of the output.
8.	Both parameters are used for output formatting and presentation.
9.	Proper use of sep and end makes program output more readable and professional.
10.	sep and end are optional parameters of the print() function.
11.	Both parameters accept string values.
12.	sep is applied between multiple output values, while end is applied after the complete output is displayed.
13.	Customizing sep and end helps create well-formatted and user-friendly output.
14.	These parameters reduce the need for extra formatting code and make programs easier to maintain.
